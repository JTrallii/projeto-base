# 🚀 Template Next.js + Supabase

Template base para projetos de demonstração com autenticação, proteção de rotas e estrutura organizada para desenvolvimento rápido de aplicações web.

## 📋 Sobre o Projeto

Este template foi criado para servir como ponto de partida para projetos que utilizam:

- **Next.js 14+** com App Router
- **Supabase** para autenticação e banco de dados
- **Tailwind CSS** para estilização
- **TypeScript** para tipagem estática
- **Componentes reutilizáveis** e estrutura escalável

Ideal para construir portfólios, demos interativas ou aplicações completas com foco em produtividade e boas práticas.

---

## ✨ Funcionalidades

- ✅ Autenticação com Supabase (login, cadastro, logout)
- ✅ Proteção de rotas via middleware
- ✅ Contexto global de autenticação (`useAuth`)
- ✅ Componentes reutilizáveis (Button, Input, Card, Layout)
- ✅ Tema escuro com glassmorphism
- ✅ Notificações com Sonner (Toaster)
- ✅ Estrutura organizada para escalabilidade
- ✅ Pronto para deploy na Vercel

---

## 🛠️ Tecnologias Utilizadas

| Tecnologia | Descrição |
| :--- | :--- |
| **Next.js 14** | Framework React com SSR e App Router |
| **Supabase** | Backend como serviço (autenticação + banco) |
| **Tailwind CSS** | Framework CSS utilitário |
| **TypeScript** | Tipagem estática para JavaScript |
| **Lucide React** | Biblioteca de ícones |
| **Sonner** | Componente de notificações |
| **Next/Font** | Otimização de fontes (Geist) |

## 📦 Pré-requisitos

Antes de começar, você vai precisar ter instalado em sua máquina:

- [Node.js](https://nodejs.org/) (versão 18 ou superior)
- [npm](https://www.npmjs.com/) ou [yarn](https://yarnpkg.com/) ou [pnpm](https://pnpm.io/)
- Uma conta no [Supabase](https://supabase.com/) (gratuita)
